# Secret Santa – Sales PLG Czech Republic

Jednostránková aplikace na losování Secret Santa. Nepotřebuje server ani databázi.

## Nasazení na GitHub Pages
1. Nahrajte `index.html` (a tento README) do repozitáře.
2. Settings → Pages → Source: *Deploy from a branch*, větev `main`, složka `/ (root)`.
3. Za chvíli poběží na `https://<uzivatel>.github.io/<repozitar>/`.

## Použití
- **Organizátor** (záložka Organizátor, heslo zná organizátor): klikne na *Vylosovat* a každému pošle zprávu s jeho kódem.
- **Kolegové**: otevřou stránku, zadají kód a uvidí, koho obdarovávají.

Vylosované kódy se pamatují jen v prohlížeči organizátora. Po rozeslání už nelosujte znovu.
